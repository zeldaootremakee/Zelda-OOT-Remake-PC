# ZeldaOOTRemakePC

**ZeldaOOTRemakePC** maps how the Legend of Zelda remake runs through Great Deku Tree zones using your own offline cartridge dump.

### Booting Your Offline Cartridge
Supply your own dumped `.nup` or extracted `romfs` image; no Nintendo assets, keys, or firmware are bundled.

Interior dungeons like the Great Deku Tree hold steadier frametimes, while open Hyrule Field paths settle once initial shaders compile.
